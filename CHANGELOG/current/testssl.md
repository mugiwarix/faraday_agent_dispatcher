[ADD] Added the `testssl` official executor, which runs testssl.sh against the configured targets and imports the SSL/TLS findings — deprecated protocols, weak or anonymous cipher suites, Heartbleed/POODLE/Logjam/SWEET32 and friends, and certificate problems — as Faraday vulnerabilities. The scan is scoped by `TESTSSL_VULN`, which accepts check names, issue names, CVE ids or Nessus plugin ids, so a single run can cover the SSL/TLS issues of the issue catalog. The executor defaults to `--nodns min`; `TESTSSL_NODNS=none` disables DNS entirely and requires an IP target, `--ip`, or `/etc/hosts`. `TESTSSL_SNEAKY` changes the HTTP user-agent only; it does not hide activity or suppress DNS. Bundled manifest `testssl-1.0.0.json`; the legacy publish Dockerfile declares testssl.sh and its dependencies, but its full image build remains unverified.
